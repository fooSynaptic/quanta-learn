# solved-list / rlhf-book

主题域：**RLHF Book** 的实验与实现排障归档。

上游阅读域：[reading-list/rlhf-book](../../reading-list/rlhf-book/)。可复用工具下游：[tool-list/rlhf-book](../../tool-list/rlhf-book/)。

## 本域收什么

- 章节配套实验跑不通、结果与预期不符时的复现与修复记录
- 训练脚本、依赖、数据管线、评测指标等**实现层**问题与解法
- 可复用的排障结论（供同主题 reading 下次命中）

## 本域不收什么

- 纯阅读笔记 / 章节摘要 → 放 `reading-list/rlhf-book/`
- 已抽象成通用启动器、评测入口的脚本 → 登记到 `tool-list/rlhf-book/`

## 条目约定

索引字段遵循 [`catalog/schema.md`](../../catalog/schema.md) 的 `solved-*`（`topics` / `summary` / `quality` 等）；物理文件按章节或问题再分子目录扩展。
